# ZMK para TOTEM

Use [AGENTS.md](AGENTS.md) para editar e validar. Para hardware e pinagem física, consulte o [projeto TOTEM](https://github.com/GEIGEIGEIST/totem).

Para flash autorizado, confira os UF2 de `totem_left` e `totem_right` do mesmo build. Entre no bootloader da metade confirmada com reset duplo; copie apenas o UF2 correspondente para o volume exposto. Repita na outra metade se necessário. Preserve o último par funcional e valide as duas metades no dispositivo antes de declarar a troca concluída.
